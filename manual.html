NetCut QA Manual

วิธีเทสต์เน็ตหลุดของ vdoc (video-call-app, online-self, video-call-agent) บนเครื่องจริง · agent ใช้ Chrome บน MacBook · ลูกค้าใช้มือถือ Android ต่อสาย USB

1. เตรียมเครื่อง (ทำครั้งเดียว)

เปิดแอป Terminal (กด ⌘ + Space พิมพ์ Terminal) แล้วทำทีละขั้น · กดปุ่ม Copy แล้ววางใน Terminal กด Enter

ขั้นที่ 1 · เช็คว่าเครื่องมีอะไรแล้วบ้าง

for c in brew git node adb docker; do printf "%-7s" $c; command -v $c >/dev/null && echo "มีแล้ว" || echo "ยังไม่มี"; done

ตัวที่ขึ้น "มีแล้ว" ข้ามขั้นนั้นได้เลย

ขั้นที่ 2 · Homebrew ต้องใช้รหัส admin

ตัวติดตั้งโปรแกรมของ Mac ที่ขั้นอื่นใช้

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

ติดตั้งเสร็จ ให้รันบรรทัดนี้ต่อ (ทำให้พิมพ์ brew ได้ทุกครั้งที่เปิด Terminal · ใช้ได้ทั้ง Mac ชิป Apple และ Intel ทั้ง zsh และ bash · รันซ้ำได้ไม่เพิ่มบรรทัดซ้ำ)

BREW=$([ -x /opt/homebrew/bin/brew ] && echo /opt/homebrew/bin/brew || echo /usr/local/bin/brew); RC=$([ "${SHELL##*/}" = bash ] && echo ~/.bash_profile || echo ~/.zprofile); grep -qs "brew shellenv" "$RC" || echo "eval \"\$($BREW shellenv)\"" >> "$RC"; eval "$($BREW shellenv)"

เช็ค: ปิด Terminal แล้วเปิดใหม่ พิมพ์ brew -v ต้องขึ้นเลขเวอร์ชัน · Homebrew ติดตั้ง git ให้ด้วย · ถ้าไม่มีรหัส admin ให้ IT ติดตั้งขั้นนี้กับขั้นที่ 4 ให้

ขั้นที่ 3 · Node และ adb

Node ใช้รัน netcut · adb ใช้สั่งมือถือผ่านสาย USB

brew install node && brew install --cask android-platform-tools

เช็ค: node -v และ adb version ต้องขึ้นเลขเวอร์ชันทั้งคู่

ขั้นที่ 4 · Docker Desktop ต้องใช้รหัส admin

brew install --cask docker
  1. เปิดแอป Docker จาก Applications
  2. กดยอมรับเงื่อนไข · หน้า sign in กด Skip / Continue without signing in ได้
  3. รอจนไอคอนวาฬบนแถบเมนูหยุดขยับ

เช็ค: docker compose version ต้องขึ้นเลขเวอร์ชัน · ไม่ต้องตั้ง port forwarding หรือค่าอื่นใน Docker Desktop

ขั้นที่ 5 · ดาวน์โหลด netcut

git clone https://github.com/thyahan/netcut.git ~/netcut

netcut จะอยู่ที่ ~/netcut (ต้องอยู่ใต้โฟลเดอร์ home)

ขั้นที่ 6 · เปิด USB debugging บนมือถือ

  1. Settings → About phone → Software information → กด Build number 7 ครั้ง จนขึ้นว่าเปิด Developer mode แล้ว
  2. Settings → Developer options → เปิด USB debugging
  3. เสียบสาย USB กับ Mac · มือถือถาม "Allow USB debugging?" ติ๊ก Always allow แล้วกด Allow
adb devices

เช็ค: ต้องเห็น 1 บรรทัดลงท้ายด้วย device · ถ้าขึ้น unauthorized ให้ดูที่มือถือแล้วกด Allow

2. เริ่มทุกครั้ง

  1. เปิด Docker Desktop และเสียบมือถือ
  2. รันใน Terminal: 
    cd ~/netcut && npm start
  3. ครั้งแรกที่ macOS ถามว่าให้ node รับการเชื่อมต่อ กด Allow (ต้องอนุญาต ไม่งั้นเคสบล็อก Vroom ใช้ไม่ได้)
  4. หน้าเว็บ netcut เปิดขึ้นมาเอง (ถ้าไม่ขึ้น เปิด http://127.0.0.1:8790) · ปล่อยหน้าต่าง Terminal ไว้ อย่าปิด
  5. มุมขวาบนต้องมีจุดเขียว 3 จุด: มือถือต่อ USB, AdGuard, DNS relay
ห้ามใช้ adb แบบ wireless และห้ามต่อ VPN ตอนเทสต์ · staging เปิดคิว 10:00–20:00

4. เคสที่เทสต์

เคสที่ไม่ได้เขียนเรื่อง DNS ให้ใช้ DNS ปกติ (DHCP) ทั้งสองเครื่อง

เคสฝั่งลูกค้า เลือกใน "ตัดเน็ตใคร" ได้ 2 แบบ ทำซ้ำอีกรอบด้วยอีกแบบได้:

  • ลูกค้า · ทั้งเครื่อง เหมือนเดินออกนอกระยะ Wi-Fi มือถือรู้ตัวทันที
  • ลูกค้า · vdoc app หรือ ลูกค้า · Chrome (online-self) เหมือนเน็ตบ้านล่มทั้งที่ Wi-Fi ยังเต็ม แอปอาจรู้ตัวช้ากว่า เพราะต้องรอ timeout · ผลของแบบนี้ยังไม่เคยเทสต์ ให้จดสิ่งที่เห็นไว้

5. ตั้ง DNS (เฉพาะ 2 เคสบล็อก Vroom)

มือถือ Android

  1. Settings → Wi-Fi → กดค้างหรือกด ⚙️ ที่เครือข่ายที่ต่ออยู่ → Advanced / View more
  2. IP settings → Static (IP, Gateway, Prefix มักกรอกให้แล้ว ถ้าว่างให้ใส่ IP ปัจจุบันของมือถือ, Gateway ของ router, Prefix 24)
  3. DNS 1 = IP ของ Mac · DNS 2 = ลบให้ว่าง → Save
  4. เช็คบนหน้าเว็บ กล่อง "บล็อก Vroom": แถวมือถือต้องขึ้น DNS เป็น IP ของ Mac และขึ้นว่า "จะโดนถ้าบล็อก"
  5. คืนค่า: IP settings → DHCP → Save

MacBook

  1. กดปุ่ม ให้ Mac โดนบล็อกด้วย ในกล่อง "บล็อก Vroom" แล้วใส่รหัสผ่านของ Mac
  2. เช็ค: แถว MacBook ขึ้นว่า "จะโดนถ้าบล็อก" (ถ้ามีคำเตือน "VPN ทับ DNS" ให้กดปุ่มนี้อีกครั้ง)
  3. หลังกด บล็อก ใน Chrome ของ agent เปิด chrome://net-internals/#dns → กด Clear host cache ก่อนเริ่มเคส (Chrome จำ DNS เองประมาณ 1 นาที)
  4. คืนค่า: กดปุ่ม คืน DNS ของ Mac แล้วใส่รหัสผ่าน
ทำไม่ได้: บล็อก Firebase อย่างเดียว (Firebase ต่อค้างไว้ตั้งแต่เปิดแอป การบล็อก DNS ตัดของที่ต่ออยู่แล้วไม่ได้) · Mac แบบ Wi-Fi ต่ออยู่แต่ไม่มีอินเทอร์เน็ต netcut ทำให้ไม่ได้ ให้จำลองใน Chrome ของ agent: DevTools → Network → Offline (ภาพและเสียงวิดีโอคอลยังไหลต่อ)
ระวัง: ตอนมือถือใช้ DNS ของ Mac ห้ามตัดเน็ต Mac (ตัวเลือก agent · Mac จะถูกกันไว้) และห้ามปิด netcut ไม่งั้นมือถือเปิดเว็บไม่ได้ คืน DNS ก่อนทุกครั้ง

6. จบการเทสต์

  1. คืน DNS มือถือเป็น DHCP และกด คืน DNS ของ Mac (ถ้าตั้งไว้) · ทั้งสองแถวในกล่อง "บล็อก Vroom" ต้องขึ้น "ไม่โดน"
  2. กด คืนทุกอย่าง
  3. กลับไปที่ terminal ที่รัน npm start แล้วกด Ctrl-C
  4. npm run stop ปิด AdGuard (Docker Desktop ปิดทิ้งได้ถ้าไม่ใช้แล้ว)
