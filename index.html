คืนเน็ตเองหลังตัด
Wi-Fi ต่ออยู่แต่ไม่มีอินเทอร์เน็ต · netcut ทำให้ไม่ได้ ให้จำลองใน Chrome ของหน้า agent:
  1. กด ⌥ ⌘ I เปิด DevTools → แท็บ Network
  2. ช่อง throttling (ปกติเขียนว่า No throttling) เลือก Offline
  3. จบเคส เลือกกลับเป็น No throttling

ข้อจำกัด: ตัด Firebase และ HTTP ได้ แต่ภาพและเสียงวิดีโอคอลยังไหลต่อ
